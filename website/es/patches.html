EVD 5.7 — parche acumulativo 7

2026-11-21

Para Windows y macOS con base 5.7.0. No es necesario instalar parches anteriores por separado. No es un instalador completo.

  • Paquete para instalar desde archivo
  • Instalador sin conexión para Windows 5.7 antiguo (ZIP)
  • Instalador sin conexión para Mac 5.7 antiguo (ZIP)

Si Ayuda incluye Instalar parche desde archivo, descargue el primer paquete, selecciónelo desde ese menú, confirme y reinicie EVD. Puede transferirlo por USB; la instalación no requiere Internet.

Si falta el menú, descargue el ZIP de su sistema y extraiga todos los archivos. Cierre EVD. En Windows abra install.cmd y seleccione EVD.exe instalado o portátil. En Mac escriba bash y un espacio en Terminal, arrastre install.command y pulse Intro; seleccione EVD. Revise los datos y confirme con 1 e Intro. Abra EVD de nuevo. La instalación y activación del instalador Mac se probaron en Apple Silicon.

Se comprueban firma, integridad, versión y plataforma. Se rechazan paquetes dañados, incompatibles o anteriores. No desactive avisos de seguridad; use el instalador completo si es necesario.

Contenido del parche

El parche acumulativo 7 para EVD 5.7 incluye todos los parches anteriores. Se corrigió la duración de una o varias fotos para cubrir el audio añadido en presentaciones. La limpieza de silencios permite seleccionar todo y desmarcar elementos individuales. Los límites de muletillas incorporan criterios mejorados de iOS, protección de palabras vecinas y límites de ajuste manual. El editor de descripciones permite congelar fotogramas para narraciones largas, desplazar eventos posteriores y mostrar un resumen de duración antes de exportar. Ayuda incluye buscar actualizaciones e instalar desde archivo. La página de actualizaciones intermedias ofrece un paquete sin conexión e instaladores separados para versiones 5.7 antiguas. Incluye las correcciones existentes de exportación por grupos para muchos cortes y mejores diagnósticos de progreso. El nuevo motor HDR para Mac y el cambio de nombre requieren un instalador completo y no están incluidos.
