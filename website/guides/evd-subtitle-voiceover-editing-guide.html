What the tool does

EVD's subtitle tool can do more than burn text into a picture. It can turn every SRT entry into TTS and let you edit each generated segment independently. Use it for spoken subtitles, audio description, educational content, language access, or any production where text must be visible, audible, or both.

  • Visible subtitles only: burn SRT text into the video.
  • Voiceover only: add the text as TTS.
  • Visible subtitles and voiceover: show and speak the updated text together.
The source video is never overwritten. EVD creates a new output, and an .evdtts project lets you resume later.

Before you begin

  • Prepare a correctly timed SRT and its matching source video.
  • For OpenAI or ElevenLabs, save the appropriate API key in the EVD AI menu.
  • System voices work offline; available languages depend on voices installed in Windows or macOS.
  • Do not move the source video, subtitle file or saved project assets while editing.
Test a few short entries first to confirm pronunciation, speed and the balance with original audio.

Open the video.

Burn subtitles, create voiceover, or do both.

Edit or skip.

Save and build.
Save a project if needed, then apply edits and create the new video.

Subtitle and voice settings

Visible subtitles

When burning subtitles, choose font, size, color, outline, background and position. Text edits made later in the segment editor also update the visible subtitles in the final video.

Voiceover defaults

  • Service: system voices, OpenAI or ElevenLabs.
  • Voice: default or a named voice from that service.
  • Speech rate: initial rate for every segment.
  • TTS volume: initial narration level.
  • Original film audio: how much the film remains audible under TTS; 0 is silent and 100 is full level.

Use Listen (Test) before generating. Start with selected settings produces the first TTS take for every SRT entry.

You can then choose Edit voiceovers or Create directly with current settings. If no individual correction is needed, skip the editor entirely.

The voiceover editor

When the editor opens, its shortcuts are announced and focus moves to the segment list. Each accessible item announces subtitle text first, then TTS start, speed, TTS level, original-audio level and whether voiceover is enabled.

  • Up/Down selects and automatically previews the previous/next segment.
  • Page Up/Page Down moves ten segments; Home/End moves to first/last.
  • Enter or Space previews the current segment.
  • Right Arrow opens the action menu. Navigate with arrows and activate with Enter; Left Arrow or Escape returns to the list.

The menu contains preview, speed, original audio, TTS level, timing, enable/disable voiceover and reset. All have direct keyboard commands.

Understand the preview

EVD starts the film approximately one second before the selected TTS start. This lets you hear whether narration overlaps dialogue or an important sound. TTS enters at its exact configured time, and preview continues briefly after the spoken audio or subtitle range.

If another voiceover overlaps the selected preview window, EVD plays that neighboring segment too. Timing collisions can therefore be detected before export rather than only in the finished video.

J/L browses the film five seconds backward/forward without changing subtitle timing and plays a short sample.

The TTS rate, TTS level and original-film level heard in preview use the same calculations as final export.

Change text and voice

Regenerate text

  1. Select a segment and Tab to Selected subtitle text.
  2. Edit the text. Use Shift+Enter for a new line.
  3. Press Enter. Only this segment is regenerated and previewed.

Pressing Enter without changing the text also creates a fresh synthesis, useful when a voice engine produces a poor reading. Updated text is used both for speech and for the saved/exported SRT.

Use a different voice for one segment

Choose a voice in Selected segment voice. Only that segment is regenerated. Other segments keep their voices, and returning to an item restores its saved selection.

Timing, speed and mix

Every adjustment immediately replays the segment with its new values.

SettingBehavior
RateF increases by 5%, A decreases, D restores the default. Range: 50%-200%.
TTS levelAlt+Shift+L/J changes by 10%, up to 200%.
Original filmAlt+Shift+Up/Down changes by 10%.
TimingG/H moves 1 ms, Alt+Left/Right 10 ms, Alt+Shift+Left/Right 100 ms, Ctrl+J/L one second.
VoiceoverV disables/enables only selected TTS. Visible subtitles remain if selected.
ResetR restores the segment's original text, timing, voice, rate and mix.

Timing commands move the subtitle/TTS segment on the film timeline; they do not move the source film. Saved edited SRT time codes reflect the same changes.

Save and open projects

Alt+Shift+S or Save Project creates an .evdtts file on first use and updates it on later saves.

Beside the project, EVD stores a project_name_assets folder containing generated TTS files and project_name_duzenlenmis.srt containing updated text and timing. The project preserves the selected index, defaults, segment voices and edits.

Resume from Add > Open Subtitle Voiceover Project or Open Another Project inside the editor.

Keep the project, assets folder, edited SRT and source video accessible together. A project cannot restore a TTS file that has been moved or deleted.

Apply edits and create output

  • Apply Edits and Create: uses all segment-specific text, voice, rate, time and mix settings.
  • Skip Editing, Create with Current Settings: uses the initial defaults and bypasses individual editing.
  • Cancel: leaves without creating output.

EVD places speech at its times, mixes it with original audio, and burns updated text/timing when visible subtitles are enabled. Progress is announced and a completion sound and file location are provided.

Troubleshooting and good practice

TTS overlaps dialogue

Move the segment in 10/100 ms or one-second steps and use the one-second lead-in to check dialogue.

Two voiceovers overlap

Neighboring TTS is included in preview. Move one segment, increase its rate, shorten its text or disable it with V.

Voiceover is too quiet

Increase TTS with Alt+Shift+L or lower the film with Alt+Shift+Down. Above 100%, listen for distortion.

Text changed but old audio remains

Press Enter in the text field, wait for regeneration, preview, and save with Alt+Shift+S.

Saved project reports a missing audio file

Restore the _assets folder beside the project and ensure the source video has not moved.

Final checklist

  1. Correct video and SRT selected.
  2. Visible subtitles, voiceover or both chosen.
  3. Service, voice, rate and initial mix tested.
  4. Every segment previewed with the film.
  5. Incorrect text or pronunciation regenerated.
  6. Overlapping TTS corrected.
  7. Important original/TTS balances checked.
  8. Project and edited SRT saved.
  9. Visible text, timing and mix checked in the final video.
