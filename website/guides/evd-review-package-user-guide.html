What a review package does

The Review Package is designed for checking a completed or nearly completed audio-description production. Source video or audio and a description script in SRT, VTT or Word format open in the same workspace. The reviewer can stop playback, locate the closest description, attach a correction note, or create an independent note where no description exists.

At the end, export only the annotated items instead of redistributing the complete script. Writers, narrators and editors receive clear corrections with time codes.

Two note types: A linked review note belongs to an existing description. An independent note records an issue such as “description missing here” even when no description event exists in that range.

Prepare the folder

Keep files for the same production in one folder:

  • One video, or MP3/WAV/M4A when reviewing audio only.
  • A description script in SRT, VTT or DOCX.
  • An existing .evdscript project, if available.

If there is one media file and one script, EVD selects them automatically. With several compatible files, choose the correct media and script in the package dialog.

Word scripts: EVD extracts time-coded descriptions. Uppercase text immediately after a time code, such as “EMOTIONAL” or “READ QUICKLY”, is separated as a narration direction. Review import warnings before opening.
Legacy .doc is not imported directly. Save it as .docx in Word.

Open the review package

From EVD

  1. Choose Add > Description / Subtitle Editor.
  2. Activate Open review package and select its folder.
  3. If the folder contains one .evdscript, it opens directly. With more than one project, EVD asks which one to use.
  4. Without a project, verify the media and description-script selections. For Word, inspect the detection preview.
  5. Activate Open selected package. When a single media/script pair is found, EVD loads it and focuses the keyboard timeline automatically.

From File Explorer or Finder

With installed EVD, use Open with EVD Review Package on the folder context menu. Pressing Enter on an associated .evdscript also opens the project.

File associations and folder context commands are normally installed by the setup version. In the portable build, open the package from within EVD.

Understand the workspace

  • Playback and expert timeline: source media, current time, waveform, markers and event blocks.
  • Event list: descriptions and independent notes in time order. The accessible label starts with description text, then its start/end time and details.
  • Event filter: all events, events with review notes, unresolved notes and other workflow states.
  • Project actions: save, save as, open and export.

Alt+T focuses playback; Alt+L focuses the event list and selects the description closest to the paused position.

Up/Down selects events in the list. On the timeline, Up/Down changes preview volume by 5% without unnecessary screen-reader announcements.

End-to-end workflow

Open the package.
Select the folder and verify media and script.
Start listening.
Press Alt+T, then Space.
Pause at an issue.
Use Enter or K.
Find the text.
Alt+L selects the closest description; use arrows for neighbors.
Write the note.
Use Alt+N for an existing description, or two M markers and A for an independent note.
Save and continue.
Ctrl/Cmd+Enter saves and returns focus to playback.
Protect the project.
Alt+Shift+S saves; autosave also runs periodically.
Export the report.
Ctrl/Cmd+Shift+E, then choose Word, TXT or Excel.

Add a note to an existing description

  1. Pause at the issue and press Alt+L.
  2. Use Up/Down to find the correct description; Space or P previews its range.
  3. Press Alt+N, or choose Add or edit review note from the Right Arrow menu.
  4. Write the correction. Enter makes a new line.
  5. Press Ctrl/Cmd+Enter. Focus returns to the timeline.

Open the same note again to edit, remove or mark it resolved. Exports can be limited to unresolved notes.

Add an independent note where no description exists

  1. Return to playback with Alt+T.
  2. Press M at the start and again at the end of the affected range.
  3. Shift+Space verifies the range.
  4. Press A; the review-note form opens with focus in the text field.
  5. Write a clear note such as “A description is missing in this range” and save with Ctrl/Cmd+Enter.
After selecting a note in the list, use G/H for 1 ms, Alt+Left/Right for 10 ms, Alt+Shift+Left/Right for 100 ms, or Ctrl+J/L for one-second timing changes.

Save and resume the project

Alt+Shift+S or Save project asks for a name the first time and creates an .evdscript. Later saves update that file; Save As creates a copy. Autosave is helpful, but save manually after important groups of corrections.

Resume with Open Project, by opening an associated .evdscript, or by selecting its folder through Open Review Package. A single project opens directly; multiple projects are offered for selection. EVD restores the saved playback position and workspace selection.

Export the review report

  1. Press Ctrl/Cmd+Shift+E or activate Export.
  2. Choose Word, TXT or Excel. By default, only descriptions with review notes and independent notes is selected.
  3. You may instead choose unresolved notes or all events. If no other setting is needed, press Enter on the format selection to begin.
  4. Confirm the destination. EVD proposes a localized name such as Greyhound-audio review report.docx and announces progress, cancellation, errors and success.
Output formats
FormatRecommended use
Word, DOCXA readable report for writers, narrators and production teams. Items are numbered; description text, time range and an H3 review-note heading are included.
TXTPlain, copyable text that opens everywhere.
Excel, XLSXFilter, sort and track many notes in columns.
SRT/VTTTransfer timed description/subtitle text to another editor. This is not a substitute for the review report.

Tips and troubleshooting

Preview is too quiet

Focus the timeline with Alt+T and hold Up Arrow. This affects monitoring only, not the source or exported file.

Alt+L selected the wrong text

EVD first selects the shortest event covering the paused position, otherwise the closest one. Check neighbors with arrows and preview with Space or P.

The folder contains many files

Verify project, media and script fields individually. Add dates or version numbers to filenames when multiple production cuts share a folder.

Media and script do not align

Confirm the correct media cut. Added or removed intros and credits can shift every time code; sample several places to determine whether one event or the whole list is affected.

The report is too large

Keep the default scope, or mark completed notes resolved and export unresolved notes only.

Quick checklist

  1. I opened the correct media and script.
  2. I paused at issues and used Alt+L to locate the correct description.
  3. I added clear, actionable linked notes with Alt+N.
  4. I recorded missing descriptions as independent notes with two M markers and A.
  5. I replayed important ranges.
  6. I saved with Alt+Shift+S.
  7. I verified that Word, TXT or Excel contains only the required notes.
  8. I archived the project, source media and report together.
