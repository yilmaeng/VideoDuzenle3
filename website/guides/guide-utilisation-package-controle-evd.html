Rôle du package de contrôle

Il sert au contrôle final d'une audiodescription terminée ou presque terminée. La vidéo/l'audio et le script SRT, VTT ou Word s'ouvrent ensemble. À l'arrêt, le contrôleur retrouve la description la plus proche, lui associe une correction ou crée une note indépendante lorsqu'aucune description n'existe.

Deux types : la note liée appartient à une description existante ; la note indépendante enregistre avec ses propres temps un problème tel que « Il manque une description ici ».

Préparer le dossier

Placez dans un même dossier : une vidéo ou un MP3/WAV/M4A, le script SRT/VTT/DOCX et, s'il existe, un projet .evdscript. Avec un seul média et un seul script, EVD les sélectionne automatiquement ; avec plusieurs, il demande votre choix.

Word : EVD extrait les descriptions horodatées. Le texte en capitales juste après le code, par exemple « ÉMOTIONNEL » ou « LIRE VITE », devient une consigne de lecture. Vérifiez l'aperçu.
Convertissez les anciens fichiers .doc en .docx.

Ouvrir le package

  1. Choisissez Ajouter > Éditeur de description/sous-titres, puis Ouvrir un package de contrôle.
  2. Sélectionnez le dossier.
  3. Un seul .evdscript s'ouvre directement ; avec plusieurs projets, EVD demande lequel.
  4. Sans projet, vérifiez média et script et, pour Word, l'aperçu de détection.
  5. Activez Ouvrir le package sélectionné. Un couple unique est chargé et la chronologie clavier reçoit le focus.

Dans la version installée, utilisez aussi Ouvrir avec le package de contrôle EVD dans le menu du dossier ou Entrée sur un projet associé. Dans la version portable, ouvrez depuis EVD.

Espace de travail

  • Lecture/chronologie experte : média, temps, onde, marqueurs et événements.
  • Liste : descriptions et notes ; le nom accessible commence par le texte puis annonce temps et détails.
  • Filtre : tous, avec note, non résolus et états.
  • Projet : enregistrer, enregistrer sous, ouvrir, exporter.

Alt+T focalise la lecture. Alt+L ouvre la liste et sélectionne la description la plus proche de la pause. Haut/Bas dans la chronologie change le volume d'aperçu de 5 %.

Note sur une description existante

  1. Arrêtez-vous et appuyez sur Alt+L.
  2. Trouvez avec Haut/Bas ; Espace ou P lit la plage.
  3. Appuyez sur Alt+N ou choisissez Ajouter/modifier la note de contrôle dans le menu Flèche droite.
  4. Écrivez ; Entrée ajoute une ligne.
  5. Ctrl/Cmd+Entrée enregistre et revient à la chronologie.

Vous pouvez modifier, supprimer ou marquer la note résolue. L'export peut ne contenir que les non résolues.

Note indépendante sans description

  1. Alt+T revient à la chronologie.
  2. Appuyez sur M au début et à la fin.
  3. Maj+Espace vérifie.
  4. Appuyez sur A ; le champ de note est focalisé.
  5. Écrivez et enregistrez avec Ctrl/Cmd+Entrée.
Réglage du temps : G/H = 1 ms, Alt+Gauche/Droite = 10 ms, Alt+Maj+Gauche/Droite = 100 ms, Ctrl+J/L = une seconde.

Enregistrer et reprendre

Alt+Maj+S demande un nom la première fois et crée .evdscript. Ensuite le même fichier est mis à jour ; Enregistrer sous crée une copie. Une sauvegarde automatique est également effectuée.

Reprenez avec Ouvrir le projet, Entrée sur le fichier associé ou le dossier du package. Un seul projet s'ouvre directement ; plusieurs sont proposés. Position et sélection sont restaurées.

Exporter le rapport

  1. Ctrl/Cmd+Maj+E ou Exporter.
  2. Choisissez Word, TXT ou Excel.
  3. Par défaut : uniquement descriptions avec note et notes indépendantes. Vous pouvez choisir non résolues ou tout.
  4. Si rien d'autre ne change, appuyez sur Entrée dans le format.
  5. Confirmez la destination ; EVD annonce progression, annulation, erreur et réussite.
FormatUsage
WordRapport numéroté avec description, temps et note sous titre H3.
TXTTexte simple à copier.
ExcelFiltrer et suivre de nombreuses notes.
SRT/VTTTransférer le texte horodaté ; ne remplace pas le rapport.

Conseils et dépannage

Volume faible : Alt+T et maintenez Haut ; seule l'écoute change. Alt+L choisit mal : vérifiez les voisins avec flèches et Espace/P. Beaucoup de fichiers : vérifiez chaque sélection. Temps décalés : confirmez le bon montage. Rapport trop long : gardez la portée par défaut ou les non résolues.

Liste de contrôle

  1. Bon média et bon script ouverts.
  2. Arrêt au problème et texte trouvé avec Alt+L.
  3. Descriptions annotées avec Alt+N.
  4. Manques notés avec deux M et A.
  5. Plages importantes réécoutées.
  6. Projet enregistré avec Alt+Maj+S.
  7. Seulement les notes utiles dans Word/TXT/Excel.
  8. Projet, média et rapport archivés ensemble.
