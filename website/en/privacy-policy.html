Accessible Video Editor (EVD) Privacy Policy

This Privacy Policy explains how personal data may be processed, stored, and protected when using Accessible Video Editor (EVD).

Application Name: Accessible Video Editor (EVD)
Publisher / Developer: Engin Yilmaz
Contact Email: engin_yilmaz@yahoo.com
Effective Date: 12.03.2026

1. Information Collected

  • User settings and preferences saved inside the application
  • Video, audio, image, and project files processed locally on the device
  • Authorization data created when the user connects a YouTube account
  • Limited application logs used for diagnostics and reliability

2. Purpose of Use

  • Providing video editing, recording, and live streaming features
  • Preserving user preferences between sessions
  • Connecting to third-party services when the user requests it
  • Improving security, stability, and user experience

3. Local Storage

Some settings and connection details may be stored locally on the user's device so the application can continue working properly. These items are not automatically sent to third parties.

4. YouTube and Third-Party Services

If the user chooses to connect YouTube, authorization is handled through Google's OAuth flow and only with the user's explicit consent.

5. Sharing of Personal Data

Personal data is not sold, rented, or shared for commercial purposes except where required by law or where the user has initiated a third-party connection.

6. Data Security

Reasonable technical and administrative measures are used to protect data, but no digital system can guarantee absolute security.

7. Data Retention

Locally stored settings may remain on the device until they are deleted by the user or until the application is removed.

8. User Rights

  • Request information about processed data
  • Request correction of inaccurate or incomplete data
  • Delete locally stored data from the application environment
  • Revoke third-party account connections
